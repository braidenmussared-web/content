# content — @builtbybraiden Content Archive

This repo is the storage and working directory for Braiden's @builtbybraiden
content output. It is NOT the business/OS repo (`braidenmuss`) — that repo
holds business logic, client systems, and the personal vault. This repo
holds the actual content assets: what gets made, drafted, and posted.

## Folder structure

- `carousels/` — Instagram carousel HTML files (built via the
  `builtbybraiden-carousel` skill)
- `captions/` — Instagram caption copy for carousels/posts
- `reels/` — Reel/short-form video scripts
- `newsletters/` — Beehiiv newsletter drafts
- `linkedin/` — LinkedIn post copy
- `case-studies/` — Client result / case study content

## Conventions

- File naming: `YYYY-MM-DD-topic-slug.ext` (e.g. `2026-09-28-client-onboarding-mistakes.html`)
- Each carousel should have a matching caption file with the same slug where possible,
  so the pair is easy to find together.
- This repo is a working archive, not a publishing pipeline — nothing here
  auto-posts anywhere yet.

## Related repos
